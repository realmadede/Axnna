# Data Ingestion Documentation\n\n## Provider Abstraction\nAll external calls go through `MarketDataProvider` and `FundamentalDataProvider` interfaces.\n\n## Incremental Sync\nA Cloudflare scheduled worker (Cron Trigger) runs incrementally syncing new completed candles to the `market_candles` table using an idempotent `UNIQUE(instrument, timeframe, timestamp)` index.\n\n## Cost Protection\nReact components never call Finnhub or Twelve Data directly. They strictly query the local `axnna_db` via `GET /api/markets` and `GET /api/calendar`, ensuring requests scale by time, not by active users.
