# Contributing to Axnna

Thank you for your interest in Axnna! 

**Please note: Axnna is a proprietary, closed-source project owned exclusively by MADEDE.**

Because this is a closed-source commercial project, we do not accept unsolicited pull requests, feature branches, or public code contributions in the way a traditional open-source repository does.

## Authorized Developers
If you are an internal team member or a contracted developer authorized by MADEDE to work on this repository:

1. **Branching:** Please create feature branches off of `main` using the format `feature/your-feature-name` or `fix/your-bugfix-name`.
2. **Commits:** Write clear, concise commit messages.
3. **Pull Requests:** Submit PRs directly to `main` and request a review from the repository owner.
4. **Confidentiality:** Do not share, distribute, or fork any part of this codebase outside of the authorized organizational environments.

For questions, permissions, or licensing inquiries, please contact MADEDE directly.
